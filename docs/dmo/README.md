# DMO · Diagnóstico de Madurez Operativa (MEBUKI)

Documentación de la iniciativa **DMO** — instrumento de diagnóstico de madurez
operativa de MEBUKI para startups y PYMEs B2B, con dos capas de uso (preventa:
6 preguntas-madre; post-venta: 96 preguntas-hijas) y enrutado hacia servicios
MEBUKI y rutas de certificación ISO 9001 / ISO/IEC 27001.
